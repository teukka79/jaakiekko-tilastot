# Jääkiekon Pistepörssi – Windows-versio (Electron)

Asennusohjelma: `Jaakiekon-Pisteporssi-Asennus-1.0.0.exe`

Rakentaminen itse (Windowsissa, Node.js 20+):

    npm install
    npm run dist

Kehitysajo: `npm start`. Tiedot tallentuvat kansioon %APPDATA%\jaakiekko-pisteporssi.
JSON-vienti ja -tuonti ovat yhteensopivia macOS- ja web-version kanssa.
